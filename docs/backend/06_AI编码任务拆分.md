# PCB 评审平台 AI 编码任务拆分

## 任务拆分原则

每个任务按一个业务垂直域交付：领域规则、数据库迁移、应用服务、REST 接口、权限校验、审计/事件影响和自动化测试同时完成。后续任务只能依赖已完成任务公开的接口与数据模型。

## 当前执行任务：任务 1（收尾）

本任务只实现评审任务域，不实现人员分配、意见闭环、文件上传或最终结束；这些由后续垂直域负责。

### 验收条件

1. 有创建草稿、提交、列表和详情接口。
2. 草稿允许保存，提交时校验任务必填字段、PCB 类型（PCB 任务）和至少一个初始文件关联。
3. 任务数据保存到 `review_task` 表，应用重启后可通过数据库查询恢复。
4. 列表支持任务名称、项目名称、设计者、评审类型、状态筛选与分页。
5. 工艺/结构专家只能查看被授权范围的任务；其他角色可查看全部任务。
6. 创建与提交记录操作审计；提交事件使用 Outbox 保存，实际邮件由任务 7 实现。
7. 自动化测试覆盖草稿、提交失败、提交成功、数据范围、分页筛选和持久化查询。
