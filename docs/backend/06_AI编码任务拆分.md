# PCB 评审平台 AI 编码任务拆分

## 任务拆分原则

每个任务按一个业务垂直域交付：领域规则、数据库迁移、应用服务、REST 接口、权限校验、审计/事件影响和自动化测试同时完成。后续任务只能依赖已完成任务公开的接口与数据模型。

## 已实施任务记录

### 本轮需求补充（2026-09-18）

- 根包及 Maven GroupId 已由 `com.leapmotor.pcbreview` 迁移为 `com.bms`；生产代码、测试、日志配置和后端架构文档已同步。
- `POST /check-item-templates/import` 已支持 `multipart/form-data` 的 Excel 批量导入。首个工作表表头必须依次包含（顺序可调整）`评审类型`、`检查项编码`、`父级检查项编码`、`检查项名称`、`排序号`、`是否启用`；评审类型支持 `PCB`/`SCHEMATIC`，启用值支持 是/否、true/false 或 1/0。任何行校验失败会使整份导入回滚。
- `GET /tasks/{taskId}/opinions` 的每条意见现返回 `designerReplies` 和 `confirmations`，包含答复轮次、答复内容、关联文件版本、答复人、答复时间与确认历史，供意见列表完整展示设计者答复。
- `GET /tasks/{taskId}/archive` 现返回结构化归档数据：`flowOpinions`（时间、阶段、操作人、意见内容及设计者答复）、`stageFiles`（阶段、文件名、上传人、上传时间，并仅冻结每条文件业务链最新版本）和 `mailRecords`（发送时间、场景、收件人、状态）。内部用户 ID 会同时返回；本地 Mock 暂用 `用户#ID` 作为显示名，待接入企业用户目录后替换为真实姓名。

### 验收条件

1. 按 PCB/原理图流程权限分配、改派评审人员和互检人员，并写入 `task_reviewer`。
2. 被分配人员可查看关联任务；“我的任务”仅返回当前节点需要其评审、分配、确认或结束的事项。
3. 评审人员可提交意见或“无意见”；同一角色多人时，必须全部提交才算该角色处理完成。
4. 互检支持任务内固定检查项实例和额外意见；已创建未完成任务的检查项随模板变更更新，已结束任务保持快照不变。
5. 自动化测试覆盖改派、无意见、多人全员完成、未分配越权和检查项规则。
